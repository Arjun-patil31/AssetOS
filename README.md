# AssetOS – IT Asset Management System

AssetOS is a web-based IT Asset Management System designed to simplify the management and tracking of IT assets within an organization. It provides a centralized platform for maintaining asset information and improving visibility into the asset lifecycle.

The project is built using Java and Spring Boot, with a focus on clean application structure, maintainability, and future enhancements.

## 🚀 Live Demo

**Live Application:** https://assetos-yfim.onrender.com

## ✨ Features

- **Asset Management:** Maintain and organize IT asset information.
- **Dashboard:** View asset-related information through a centralized interface.
- **Employee Management:** Support employee-related asset management workflows.
- **Asset Tracking:** Help monitor asset allocation and status.
- **Responsive Interface:** Designed to provide a usable experience across different screen sizes.
- **Future Enhancements:** A foundation for additional asset lifecycle, reporting, and administration features.

*Feature availability depends on the current implementation. Planned features may be added in future updates.*

## 💻 Run the Project Locally

### Prerequisites

- Java Development Kit (JDK) 21
- Git
- An internet connection for the initial dependency download

### 1. Clone the repository

```bash
git clone https://github.com/Arjun-patil31/AssetOS.git
```

### 2. Open the project directory

```bash
cd AssetOS
```

### 3. Run the application on Windows

```bash
.\mvnw.cmd spring-boot:run
```

Alternatively, build the project first:

```bash
.\mvnw.cmd clean package
```

### 4. Open the application

Once the application starts successfully, visit:

http://localhost:8080

If a different port is configured, use the port shown in the application logs.
